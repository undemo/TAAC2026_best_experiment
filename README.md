# TAAC2026

0.82617 方案开源分享

我们主要的优化点为：
## 1.PM head 0.807 -> 0.811
把四路行为序列分别做全局平均、最近 recent_k 行为平均，再算 recent - memory，再拼上 NS token 的平均表示和误差范数，最后压成一个 64 维特征，和 baseline 原本输出拼起来进分类头。
可以额外告诉模型“用户长期兴趣、近期兴趣、近期相对长期的漂移”。
	
## 2.时间特征 0.811 -> 0.820
第二个大收益点是加入时间特征TimeToken。把样本发生的北京时间小时、星期、日内周期、凌晨标记，以及四路序列的最近时间 gap、平均 gap、最大 gap 等汇总成 1 个 TimeToken，追加到 NS token 流里。
做到了既让每条历史行为知道“离现在多久”，也让模型知道“这个样本发生在什么时间段、用户近期活跃不活跃”。
	
## 3.ns_group 分组 + token 位置调整
0.820 -> 0.822
官方 baseline原始做法容易把很多离散特征都当成一堆无语义 token；这里把 user/item int 特征按语义合并成少数 token
不要让模型自己从几十个零散特征里猜结构，先按“用户上下文 / 用户画像统计 / 用户尾部标志 / item 低基数 / item 行为类 / item ID 类”等含义打包。
	
## 4.Missing-aware 特征处理 0.822 -> 0.826173
缺失不是简单填 0，而是把“这个字段缺了”当成一个可学习信号，因为缺失模式本身可能和点击/转化有关。
	
## 一直没解决的问题 / 掉分尝试：
1.尝试过对 UE 做更细的拆分和 pair 处理，但线上没有带来收益，甚至出现下降。
2.虽然全局时间特征收益很大，但把时间信息进一步加到序列侧并没有稳定提升，可能是引入了额外噪声，或者和现有序列编码方式不匹配。
3.尝试过 DIN 方向的兴趣建模，但效果一直不好.
4.黎曼投影、注意力门控、候选 token 等结构改进 这些结构方向都做过尝试，但基本没有稳定收益，部分还会掉分。
